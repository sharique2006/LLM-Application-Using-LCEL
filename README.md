# LLM-Application-Using-LCEL
This project is a simple LLM translation application built using LangChain and Groq. It uses FastAPI and LangServe to create an API for the LangChain chain and Streamlit as the client interface. 

 
What I Learned
- Building LLM applications using LangChain
- Creating prompt templates
- Creating chains using LCEL (LangChain Expression Language)
- Using StrOutputParser
- Serving LangChain chains with LangServe
- Creating APIs with FastAPI
- Connecting a Streamlit client with a backend API
- Using Groq LLMs
- Working with environment variables and API keys
- Understanding the flow between frontend, API, LangChain, and LLM
Technologies Used
- Python
- LangChain
- LCEL
- Groq
- GPT-OSS-20B
- FastAPI
- LangServe
- Streamlit
- Uvicorn
- python-dotenv
